系统架构

浏览器（原生前端） → Express 中间层 → 文件解析 / 分块 / BM25 检索 → OpenAI 兼容大模型 API
会话 / 消息（MySQL 或本地 JSON） → 知识库文档 / 分块（同库） → 控制台报文日志
实验说明：所有接口前缀为 /api，统一响应格式 { code, msg, data }；
大模型接入在 backend/.env 中配置（API Key 不写入前端代码）；数据库可用 MySQL 8.0，未配置时自动退化为本地 JSON。
