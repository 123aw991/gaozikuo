# 智能体提示词（yuanlei_prompt.md）

> 本文件汇总本项目使用的系统提示词与 RAG 拼装规则，供实验报告「提示词工程」部分直接引用。
> 实现位置：`backend/services/context.js`（拼装）、`backend/services/prompt`（见下方）、问答链路 `backend/routes/ai.js`。

---

## 1. 系统提示词（system prompt）

```
你是一个「企业知识库问答助手」。
请严格依据【参考资料】回答用户问题，遵守以下规则：
1. 只能使用【参考资料】中的事实；若资料未涵盖，明确回答「资料中未提及」，不得编造。
2. 回答应条理清晰、简明扼要，必要时分点说明，可适当使用 Markdown。
3. 必须在答案中标注来源：依据第 n 段资料时，在句末用 [n] 标注（n 为参考资料编号）。
4. 若用户问题与知识库无关（如闲聊），可正常作答，但无需标注来源。
5. 语言与用户提问保持一致（默认中文）。
```

---

## 2. 用户消息拼装（RAG 上下文）

`context.js` 在调用大模型前构造 `messages`：

```
[
  { role: "system", content: <系统提示词> },
  ...历史消息（最近 N 轮，可选）,
  { role: "user", content:
      "【参考资料】\n[1] 文件名A · 第x段：……\n[2] 文件名B · 第y段：……\n\n【用户问题】\n" + 用户问题
  }
]
```

- 参考资料来自 `rag.retrieve(query, topK)` 的 BM25 命中结果，按相关度降序编号。
- 命中分块文本经清洗（去除多余空白）后拼接，超长时按 `maxContextChars` 截断。
- 历史消息默认保留最近 6 轮，避免超出上下文窗口。

---

## 3. 检索增强（Retrieval）

- 切分：`services/rag.js` 将文档按约 420 字/块、80 字重叠切分，优先在句末断开。
- 检索：BM25（中文按 bigram 分词，英文按词），`k1=1.5, b=0.75`，取 Top-K（默认 4）。
- 引用：`citations[]` 返回 `filename / seq / score / rel / text`，前端在回答下方以可展开卡片展示。

---

## 4. 离线演示模式提示词

当 `.env` 中 `LLM_MOCK=true` 时，`services/llm.js` 不调用真实接口，直接返回模拟流式文案（含知识库相关话术），用于无网络/无额度时验证前端渲染与请求/响应日志链路。

---

## 5. 调优建议（实验可写）

- 提高 `temperature` 更发散，降低更严谨：问答场景建议 `0.2~0.4`。
- `topK` 越大召回越全但噪音越高，建议 3~5。
- 对「资料未提及」类问题，可在 system prompt 中强调拒答边界，降低幻觉。
