图二 · 智能客服系统 ER 图

erDiagram 
erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--|{ MESSAGE : "包含"
    SESSION }o--|| CHANNEL : "来自"
    SESSION ||--o{ TICKET : "产生"
    TICKET }o--|| AGENT : "受理"
    AGENT ||--o{ TICKET : "处理"
    MESSAGE }o--o{ KB_CHUNK : "引用"
    KB_CHUNK }o--|| KB_DOC : "切分自"
    KB_DOC }o--|| KB_CATEGORY : "归属"
    SESSION ||--|| FEEDBACK : "评价"
    FEEDBACK }o--|| BADCASE : "沉淀"

    USER {
        bigint user_id PK "用户ID"
        varchar nickname "昵称"
        varchar phone "手机号"
        tinyint vip_level "会员等级"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "用户ID"
        int channel_id FK "渠道ID"
        varchar status "进行中-已结束"
        tinyint robot_rate "机器人解决率"
        datetime start_time "开始时间"
    }
    MESSAGE {
        bigint msg_id PK "消息ID"
        bigint session_id FK "会话ID"
        tinyint sender "0用户-1机器人-2坐席"
        text content "消息内容"
        varchar intent "命中意图"
        float confidence "意图置信度"
        datetime send_time "发送时间"
    }
    TICKET {
        bigint ticket_id PK "工单ID"
        bigint session_id FK "来源会话"
        bigint agent_id FK "受理坐席"
        varchar category "问题分类"
        varchar status "待处理-已完结"
        datetime close_time "完结时间"
    }
    AGENT {
        bigint agent_id PK "坐席ID"
        varchar agent_name "坐席姓名"
        varchar skill_group "技能组"
        tinyint online "在线状态"
    }
    KB_DOC {
        bigint doc_id PK "文档ID"
        int category_id FK "分类ID"
        varchar title "文档标题"
        varchar source "PDF-网页-工单"
        datetime updated_at "更新时间"
    }
    KB_CHUNK {
        bigint chunk_id PK "知识块ID"
        bigint doc_id FK "所属文档"
        text content "语义分块内容"
        vector embedding "向量索引"
        int hit_count "命中次数"
    }
    KB_CATEGORY {
        int category_id PK "分类ID"
        varchar category_name "分类名称"
    }
    FEEDBACK {
        bigint feedback_id PK "评价ID"
        bigint session_id FK "会话ID"
        tinyint score "满意度1-5"
        varchar tags "问题标签"
    }
    BADCASE {
        bigint case_id PK "badcaseID"
        bigint feedback_id FK "来源评价"
        varchar reason "错误原因"
        tinyint handle_status "0待处理-1已回流"
    }
    CHANNEL {
        int channel_id PK "渠道ID"
        varchar channel_name "网页-App-微信-电话"
    }

核心实体：用户（USER）发起会话（SESSION），会话包含多角色消息（MESSAGE）；低置信会话产生工单（TICKET）由坐席（AGENT）受理；知识侧按「分类 → 文档 → 语义块（KB_CHUNK，含向量）」组织，供 RAG 引用；满意度评价（FEEDBACK）沉淀 badcase 回流知识库。
