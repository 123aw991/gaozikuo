智言云 · 智能客服系统 产品手册（V3.2）
一、产品概述
智言云智能客服系统是面向电商与 SaaS 企业的一站式客户服务解决方案，融合大语言模型、知识库检索增强（RAG）、多轮对话管理与人工坐席协同能力。系统支持网页、App、微信、企业微信、电话 IVR、开放 API 六大接入渠道，帮助企业将重复性咨询的自动解决率提升至 75% 以上。
系统由六层构成：渠道接入层、接入与会话层、对话理解与编排层、知识检索增强层（RAG）、大模型服务层、业务与人工协同层，底部由数据与知识底座支撑，并有贯穿全链路的安全合规与可观测能力。

二、核心功能模块
1. 知识库管理：支持 TXT、Markdown、PDF、Word（doc/docx）、PowerPoint（ppt/pptx）等文件上传，系统自动完成解析、清洗、语义分块与向量化，支持知识分类、版本管理与命中率统计。
2. 智能问答：基于检索增强生成（RAG），先召回再生成，回答附引用来源，可回溯到原文片段，显著降低模型幻觉。
3. 多轮对话：支持意图识别、槽位抽取、追问澄清与上下文记忆，单会话最长支持 30 轮上下文。
4. 人工协同：当置信度低于阈值、用户表达强烈不满或明确要求时，自动转接人工坐席，并同步完整会话上下文与客户画像。
5. 质检与运营：全量会话自动质检，输出解决率、满意度（CSAT）、平均响应时延、转人工率等指标，支持 badcase 回流知识库。

三、技术规格
1. 模型：内置 deepseek、qwen 等主流大模型，支持私有化部署与自有模型接入，兼容 OpenAI 接口规范。
2. 检索：混合检索（向量召回 + BM25 关键词召回），重排序（Rerank）后取 Top-K 片段，默认 K=4，单片段约 400 字。
3. 性能指标：单轮问答首字响应时延小于 1.5 秒；系统支持 5000 并发会话；知识库单库最大支持 50 万条分块。
4. 部署方式：公有云 SaaS、专属云、本地化私有部署三种模式；私有部署最低配置为 8 核 32G，GPU 显存 24G。
5. 安全合规：数据传输全程 TLS 1.3 加密，支持敏感词过滤、PII 数据脱敏、会话留痕审计与权限分级管理。

四、集成与开放能力
1. 提供 RESTful API 与 WebSocket 流式接口，SDK 覆盖 Web、iOS、Android、小程序。
2. 支持与企业微信、钉钉、飞书、CRM、工单系统双向同步。
3. 支持自定义函数调用（Function Call），可对接订单查询、物流跟踪、退款申请等业务系统。

五、版本与授权
标准版：包含 2 个知识库、3 个坐席账号，按年授权；专业版：包含 20 个知识库、50 个坐席账号，支持混合检索与模型微调；旗舰版：不限知识库数量，支持私有化部署与专属模型训练。所有版本均提供 7×12 小时技术支持，旗舰版提供 7×24 小时专属服务。
